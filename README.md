# Patient-Level Evaluation of Biomedical Machine Learning

**Status:** Study started September 2026 · ongoing

This is an independent computational study I am using to learn and test a question that came up while working with biomedical data:

> **How does patient-level dependence change the estimated performance and error profile of conventional machine-learning models on repeated biomedical observations?**

The dataset contains repeated observations from the same people. That makes the usual row-level train/test split worth questioning. Two rows can look like separate examples to a model while still carrying information about the same patient.

I want to see how much the estimated performance changes when the evaluation is changed so that patients, rather than individual observations, define the separation.

I am deliberately keeping the study small and auditable. The goal is not to build the most complicated model. The goal is to understand the data, make the evaluation choice explicit, compare defensible baselines, inspect the errors, and be clear about what the experiment can and cannot establish.

## Research question

**How does patient-level dependence change the estimated performance and error profile of conventional machine-learning models on repeated biomedical observations?**

## What I plan to do

1. Record the dataset provenance and understand the unit of observation.
2. Inspect the repeated-measure structure and perform exploratory analysis.
3. Build a simple baseline and conventional regression models.
4. Compare an observation-level evaluation with a patient-grouped evaluation.
5. Check for leakage and preprocessing mistakes.
6. Inspect error patterns rather than relying on one summary metric.
7. Run at least one reasonable sensitivity/robustness analysis.
8. Write down the limitations before drawing conclusions.

The exact model set and evaluation procedure may change as I understand the data better. I will record those decisions rather than silently changing them.

## Dataset

The study uses the **UCI Parkinsons Telemonitoring** dataset:

- 5,875 voice recordings
- 42 people with early-stage Parkinson's disease
- repeated observations for the same subjects
- regression targets: motor UPDRS and total UPDRS
- biomedical voice measurements as predictors

Source: [UCI Machine Learning Repository — Parkinsons Telemonitoring](https://archive.ics.uci.edu/dataset/189/parkinsons%2Btelemonitoring)

Dataset DOI: `10.24432/C5ZS3N`

The dataset is not committed to this repository. See `data/provenance.md` for the source record and citation.

## Current state

The repository is a starting point for the study. Results are intentionally not written into the README before the analysis exists.

The first milestone is simply to make the environment work, establish provenance, inspect the data, and freeze the evaluation question before looking at final model comparisons.

## What this study does not claim

This is not a clinical validation study, and it does not establish that a model is clinically useful. The dataset is limited in size and population, and the analysis is intended to study evaluation behaviour and methodological risk rather than make a clinical prediction claim.

## Reproducibility

The environment is specified in `requirements.txt`. As the work develops, I will record important package versions, data provenance, preprocessing choices, model settings, and analysis decisions.
