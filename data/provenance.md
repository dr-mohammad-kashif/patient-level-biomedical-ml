# Data Provenance

## Dataset

**Parkinsons Telemonitoring** — UCI Machine Learning Repository.

- Dataset ID: 189
- DOI: `10.24432/C5ZS3N`
- Source: https://archive.ics.uci.edu/dataset/189/parkinsons%2Btelemonitoring
- Dataset description: repeated biomedical voice measurements from people with early-stage Parkinson's disease.

## Study-relevant structure

The dataset contains 5,875 voice recordings from 42 people. Repeated observations are therefore central to the evaluation question in this project.

## Local data policy

The downloaded source files are intentionally excluded from Git version control. Reproducibility will rely on the recorded source, DOI, documented preprocessing, and analysis code.

## Citation

Tsanas, A. & Little, M. (2009). *Parkinsons Telemonitoring*. UCI Machine Learning Repository. https://doi.org/10.24432/C5ZS3N.
